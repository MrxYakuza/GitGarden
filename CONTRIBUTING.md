# Contributing to GitGarden

Thanks for helping the garden grow.

## Local setup

1. Fork and clone the repository.
2. Run `npm install`.
3. Copy `.env.example` to `.env.local`.
4. Add a server-side GitHub token if you want real contribution data.
5. Run `npm run dev`.

## Pull requests

- Keep changes focused and explain the user-facing result.
- Preserve keyboard access, readable contrast, and reduced-motion support.
- Never expose GitHub tokens in browser code.
- Run `npm run build` before opening a pull request.

Good first contributions include new garden themes, accessibility improvements,
tests for the garden model, and documentation translations.
